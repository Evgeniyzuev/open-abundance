## Как проверяют первые покупатели

1. Статус «бета, сделано ИИ» в карточке продукта.
2. Особая цена первой волны и безусловный возврат.
3. Челлендж «Полезный отзыв» (Core +1 $): что помогло, чего не хватило, одно предложение улучшения.
4. Правки по отзывам вносит ИИ; версия и список правок указываются в карточке.
5. Выход из беты по заранее известным условиям: достаточно покупателей, мало возвратов, оценка не ниже порога, правки внесены. Условия числом задаём при запуске.

## Проверка качества перед запуском (ИИ делает, человек просматривает один раз)

- Нет обещаний дохода и результата, который не зависит от читателя.
- Нет юридических и налоговых советов.
- Примеры вымышленные и помечены как примеры.
- Каждый лист заканчивается проверяемым действием.
- Тексты читаются человеком без подготовки (проверьте на одном человеке не из OA).

## Запуск через Маркет (реализовано 2026-10-25)

Продукты продаются как обычные объявления Маркета от аккаунта OA. Эскроу, отзывы, споры и возврат работают как у любой сделки.

**Как это устроено**
1. Объявление создаёт оператор запросом к `POST /api/internal/marketplace/oa-products` (заголовок `x-marketplace-internal-secret`, значение `MARKETPLACE_INTERNAL_SECRET` или `CRON_SECRET`). Тело: `{"productKey": "start-kit", "price": 3}`. Цена задаётся здесь, при запуске каждого продукта. Ключи: `start-kit`, `ten-conversations`, `first-sale-texts`. Один открытый листинг на продукт.
2. Когда человек оформляет покупку, сделка принимается и выдаётся сразу (сервер вызывает принятие и выдачу от имени аккаунта OA). Ждать продавца не нужно.
3. Текст открывается на странице `/products/<ключ>` только тому, у кого есть своя сделка на этот продукт в статусе «принята», «выдана» или «завершена». Остальные получают «Продукт не найден».
4. Покупатель подтверждает получение (деньги уходят в OA) или открывает спор. Если не отвечает, срабатывают обычные таймеры Маркета.
5. Отзыв оставляется в сделке как обычно. Челлендж «Полезный отзыв» пока можно вести вручную; отдельная проверка по отзыву к продукту OA ещё не сделана.

**Цены первой волны (2026-10-27).** Стартовый набор $3, «10 разговоров» $2, «Первая продажа» $2. Логика: цифровой файл без себестоимости, у первых участников небольшие балансы Wallet, бета с безусловным возвратом. Пересмотреть после 10 продаж или по отзывам.

```
for p in "start-kit 3" "ten-conversations 2" "first-sale-texts 2"; do set -- $p
  curl -sS -X POST https://open-abundance.vercel.app/api/internal/marketplace/oa-products \
    -H "content-type: application/json" -H "x-marketplace-internal-secret: $MARKETPLACE_INTERNAL_SECRET" \
    -d "{\"productKey\": \"$1\", \"price\": $2}"; echo; done
```

**Шаги оператора**
1. Создать аккаунт OA (отдельный пользователь) и взять его `user_id`.
2. Задать переменную окружения `OA_SELLER_USER_ID` с этим id и убедиться, что есть `MARKETPLACE_INTERNAL_SECRET`.
3. Для каждого продукта вызвать эндпоинт с ценой первой волны.
4. Купить один продукт со второго аккаунта и проверить: сделка принялась и выдалась, `/products/<ключ>` открылся, у чужого аккаунта нет доступа.

**Если нужно поменять текст продукта**
Правится файл в `docs/products`, затем `node scripts/build-oa-products.mjs` (тест `test:oa-products` проверяет, что сгенерированный файл свежий). Новые покупатели видят новую версию; прежние тоже, потому что доступ идёт к текущему тексту.

**Что остаётся на потом:** отдельная витрина «Продукты OA» и раздел «Мои продукты», проверка челленджа «Полезный отзыв» по отзывам именно на продукты OA, версии продуктов.
