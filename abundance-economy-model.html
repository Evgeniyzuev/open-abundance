Модель экономики Abundance

Сценарный прогноз Treasury, Wallet, Core, вознаграждений и внутреннего рынка. Предустановленные значения демонстрационные; все параметры изменяемы, расчёт выполняется локально.

Важно: это сценарная модель, а не гарантия дохода, внешней ликвидности или возможности вывода. Core — внутренняя невыводимая величина; прогноз Wallet-выплат служит для планирования резерва.
Период и резерв

Текущее покрытие = Treasury / Wallet. Покрытие с будущими выплатами дополнительно включает прогноз Wallet-выплат от существующего Core. «Доп. Core в резерве» показывает только запас планового Wallet-резерва, а не разрешённую награду.

Ликвидность и расходы

Один знаковый поток задаёт среднюю динамику: плюс пополняет Treasury и Wallet 1:1, минус создаёт запрос на вывод. Постоянные внутренние услуги и комиссии сжигают Wallet, но сами по себе не уменьшают Treasury.

Core и вознаграждения

Ставка и лидерский бонус соответствуют текущей модели. Реферальная награда и комиссии Wallet → Core — экспериментальные, по умолчанию нулевые.

Marketplace

Marketplace — отдельный оборотный контур. Покупки и продажи перераспределяют Wallet между участниками; на совокупное обеспечение влияют только сожжённые комиссии.
