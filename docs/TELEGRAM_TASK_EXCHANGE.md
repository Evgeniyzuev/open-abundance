# Задание для биржи заданий в Telegram: регистрация в Open Abundance

Статус: 2026-10-23. Готовый текст для бота биржи и автоматическая проверка. Проверка только читает базу и ничего не меняет. Очередь и статусы ведутся только в [MASTER_KANBAN.md](MASTER_KANBAN.md).

## Что считаем выполнением

- **Регистрация** — человек вошёл через бота (`https://t.me/open_abundance_bot/OpenA`). В базе появляется запись `telegram_accounts` с его @username. Это проверяется автоматически.
- **Второй уровень** — уровень 2 требует 4 Core. При регистрации даётся 2 Core (уровень 1), а челлендж «Выбери главное желание» (нужно одно желание, проверка автоматическая) даёт ещё 2 Core: итого 4. Это самый короткий путь ко второму уровню, без денег и ожидания других людей. Проверяется автоматически: уровень в `core_accounts` и число желаний.

Награду исполнителям платит биржа, не Open Abundance. Обещаний дохода в тексте нет.

## Текст задания (вариант 1: регистрация и второй уровень)

Скопируйте целиком и пришлите боту биржи. Первая строка — название.

```text
Зарегистрируйтесь в Open Abundance через Telegram и получите 2 уровень

✅ Требования:

1. Аккаунт Telegram с именем пользователя (@username): его можно задать в «Настройки» → «Имя пользователя». Он нужен для проверки.
2. Вы ещё не были зарегистрированы в Open Abundance.

📌 Инструкция:

1. Откройте приложение по ссылке: https://t.me/open_abundance_bot/OpenA
2. Нажмите «Продолжить как …». Аккаунт создаётся в один тап, ничего вводить не нужно.
3. Откройте «Желания» (сердце в нижнем меню) и добавьте одно желание: выберите готовое во вкладке «Рекоменд.» или нажмите «Добавить» и напишите свою строку.
4. Откройте «Челленджи», найдите «Выбери главное желание», нажмите «Принять челлендж», затем «Проверить выполнение».
5. После этого в профиле будет «Уровень 2».

📸 Доказательство выполнения:

Пришлите ваш @username в Telegram (как в настройках Telegram). Проверка автоматическая: мы увидим, что вы вошли через бота, и какой у вас уровень, поэтому скриншот не нужен. Если хотите, приложите скриншот профиля с уровнем 2.
```

## Текст задания (вариант 2: только регистрация)

```text
Зарегистрируйтесь в Open Abundance через Telegram (в один тап)

✅ Требования:

1. Аккаунт Telegram с именем пользователя (@username): «Настройки» → «Имя пользователя».
2. Вы ещё не были зарегистрированы в Open Abundance.

📌 Инструкция:

1. Откройте приложение по ссылке: https://t.me/open_abundance_bot/OpenA
2. Нажмите «Продолжить как …». Аккаунт создаётся сразу, вводить ничего не нужно.
3. Дождитесь главного экрана приложения.

📸 Доказательство выполнения:

Пришлите ваш @username в Telegram. Проверка автоматическая: мы увидим, что вы вошли через бота. Скриншот не нужен.
```

## Как проверять исполнителей

Исполнители присылают @username. Проверка запускается на вашем компьютере из папки проекта, ей нужен `.env` с ключами базы:

```text
pnpm tg:check @name1 @name2 --since=2026-10-23
pnpm tg:check --file=usernames.txt --since=2026-10-23
```

В `usernames.txt` можно списком: через пробел, запятую или с новой строки. `--since` — дата запуска задания: аккаунты, созданные раньше, помечаются `OLD ACCOUNT` (человек уже был в приложении, задание для новых).

Вердикты:

| Вердикт | Значит |
|---|---|
| `NOT FOUND` | Через бота с таким @username никто не входил (опечатка, другой @username, не выполнил). |
| `REGISTERED` | Вошёл через бота, второго уровня ещё нет. |
| `LEVEL 2` | Вошёл, у него уровень 2 или выше и есть желание. |
| `OLD ACCOUNT` | Аккаунт создан раньше даты `--since`. |

Для варианта 1 принимайте `LEVEL 2`; для варианта 2 достаточно `REGISTERED` или `LEVEL 2`.

## Ограничения, о которых стоит знать

- **Проверка идёт по @username.** Кто-то может прислать чужой @username. Чтобы это отсечь, смотрите колонку `created`: аккаунт должен быть создан после запуска задания. Если @username поменяли после входа, запись в базе остаётся со старым (запись обновляется при следующем входе).
- **Один Telegram — один аккаунт.** Повторно «зарегистрироваться» с тем же Telegram нельзя, так что накрутка одним человеком ограничена числом его Telegram-аккаунтов.
- **Человечность не проверяется.** Второй уровень не доказывает, что это реальный человек: это отдельная задача (HUMAN-001). Для биржи этого, как правило, достаточно.
- **Без @username автоматической проверки нет.** Поэтому он указан в требованиях.
- **Исполнителям без нового аккаунта** (уже были в приложении) задание не засчитывается, поэтому в требованиях сказано «ещё не были зарегистрированы».
