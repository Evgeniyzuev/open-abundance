# Blogger / Creator Outreach Plan

Этот документ фиксирует предложение для блогеров, создателей контента и лидеров мнений — как они могут монетизировать привод аудитории в Open Abundance, строить команду и получать доход от роста участников.

## 1. Проблема и решение

### Проблема блогера
- Аудитория есть, но монетизация нестабильна: реклама, донаты, подписки.
- Нет инструмента, который превращает подписчиков в активных участников с проверяемым ростом.
- Нет долгосрочного пассивного дохода от сообщества.

### Решение Open Abundance
- Блогер получает **реферальную ссылку** → приводит аудиторию → участники растут в Core → блогер получает **10% от суточного прироста Core** каждого прямого участника команды.
- Командный бонус начисляется ежедневно, не забирается у участников, является дополнительной системной эмиссией.
- Блогер строит команду, получает Лидерство (capacity = level × 10), может вести до 10+ участников на 1 уровне и больше по мере роста.

## 2. Что получает блогер

| Механика | Описание |
|---|---|
| Реферальная ссылка | Персональный QR/ссылка/Copy/Share в профиле |
| Командный бонус | 10% от суточного прироста Core прямых участников в его Core |
| Лидерство (capacity) | level × 10 — сколько участников может вести |
| Приоритет назначения | Реферал сначала попадает к пригласившему, если есть место |
| Публичный профиль | Уровень, Core, команда — социальное доказательство |
| Канал лида | Автоматическая подписка участников на посты лида |
| Контакты команды | Лид видит прямых участников, участники видят лида |

## 3. Что нужно сделать блогеру

1. Зарегистрироваться, пройти onboarding, получить первый Core.
2. Достичь уровня 2+ (через челленджи и daily rate).
3. Разместить реферальную ссылку в своих соцсетях (Telegram, Instagram, YouTube, TikTok).
4. Приводить новых пользователей → они автоматически попадают в команду.
5. Помогать участникам расти: давать задания, проверять прогресс, публиковать результаты.
6. Получать ежедневный командный бонус в Core.

## 4. Статус реализации

### Реализовано (2026-07-24):
- Referral claim, выбор лида, очередь и командная связь в одной идемпотентной транзакции.
- Референр уровня 2+ с достаточным Лидерством имеет первый приоритет.
- Поиск по дереву реферера, глобальный подбор, защита от циклов.
- `team_assignment_queue`, `team_membership_events`, preview/apply-инструменты.
- Очередь раз в час, полный reconciliation раз в сутки.
- Мягкий переход при росте уровня.
- QR-код, Copy, Share реферальной ссылки в профиле.
- `user_contacts` с синхронизацией team-контактов.
- Командный бонус: миграция подготовлена.

### Не реализовано (необходимо для блогеров):
- **Рабочая панель команды** — экран, где лид видит участников, их прогресс, свободное Лидерство.
- **Личный чат лид → участник** — для целей, обратной связи, заданий.
- **Групповой чат команды** — для общих задач, ритма, модерации.
- **Задачи от лида** — создание, назначение, проверка, дедлайн.
- **Публичный профиль лида** с призывом "Попробовать с этим лидером".
- **Перенос обязательной подписки на ленту лида** (feed_subscriptions).
- **Отдельный Direct** и поиск пользователей.
- **UI смены лида** с отображением cooldown.

## 5. Предложение для блогера (текст для лендинга/приглашения)

> **Стань лидером Open Abundance**
>
> Твоя аудитория — твой актив. Приводи людей в Open Abundance, помогай им расти и получай 10% от их ежедневного роста Core.
>
> — Получай персональную реферальную ссылку и QR-код
> — Строй команду: чем выше твой уровень, тем больше участников ты можешь вести
> — Ежедневный пассивный бонус от роста твоей команды
> — Публичный профиль с уровнем, Core и достижениями
> — Инструменты для работы с командой: чаты, задачи, проверка прогресса
>
> Минимальный вход: уровень 2 в Open Abundance.
