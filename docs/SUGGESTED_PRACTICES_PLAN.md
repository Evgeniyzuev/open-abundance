# Предлагаемые практики (Suggested Practices)

## Идея

Добавить в раздел **Goals → Checks** сворачиваемую секцию "Предлагаемые" с шаблонами практик осознанности и популярных привычек. Пользователь может одним нажатием добавить практику себе и начать ежедневно отмечать выполнение.

**Источник:** концепция из видео "Как изменить жизнь" (колесо сансары, наблюдатель, фиксация внимания, энергетические дыры, состояние ребёнка) + популярные привычки для саморазвития.

---

## Что добавить в UI

### 1. Новая секция "Предлагаемые" в Checks

Сворачиваемая секция **над** "Остальные", но **под** "Сегодня":
```
[▼] Предлагаемые (6)
  ┌─────────────────────────────────┐
  │ 🧘 Наблюдатель                  │  [Добавить]
  │ 3× в день check-in своего       │
  │ состояния                       │
  ├─────────────────────────────────┤
  │ 🌅 Утренний ритуал              │  [Добавить]
  │ Настройка дня после пробуждения │
  ├─────────────────────────────────┤
  │ ...                             │  [Добавить]
  └─────────────────────────────────┘
[▼] Остальные (3)
[...]
[▼] Завершенные (12)
```

### 2. Переименовать "Завершенные и удаленные" → "Завершенные"

Текущий заголовок `tasks.archive` меняется на просто "Завершенные".

## Каталог практик

Каждая практика — это предустановленный TaskItem с:
- `schedule: { type: "daily", startDate: today, infinite: true }`
- `streak: { softMode: true, initialLives: 0, livesEveryDays: 0 }`
- Готовым `title`, `description`, `imageUrl` (иконка как data URL или emoji)

### Из видео "Как изменить жизнь"

| # | Название | Эмодзи | Описание | Период |
|---|----------|--------|----------|--------|
| 1 | **Наблюдатель** | 🧘 | 3 раза в день: "Что я чувствую? О чём думаю? Я в программе или наблюдаю?" | daily |
| 2 | **Утренний ритуал** | 🌅 | После пробуждения: визуализация цели + намерение на день + главная задача | daily |
| 3 | **Вечерний ритуал** | 🌙 | Перед сном: благодарность (3 пункта) + разгрузка мыслей в заметки | daily |
| 4 | **Аудит энергии** | ⚡ | Еженедельно: закрыть дела, минимизировать токсичное общение, проверить соцсети | weekly |
| 5 | **Переключение состояния** | 🔄 | При упадке: признать состояние → движение/дыхание/вода → вернуть внимание к цели | daily |
| 6 | **Фиксация внимания** | 🎯 | Выбрать 1 главную цель на день, создать якорь-напоминание, возвращать внимание | daily |
| 7 | **Состояние ребёнка** | 🧒 | Раз в неделю: вспомнить детское увлечение и сделать это без цели на результат | weekly |

## Техническая реализация

### Хранение

Все практики — это предустановленные TaskItem, которые хранятся:
1. **Константа PRACTICE_TEMPLATES** в `lib/tasksStore.ts` (или отдельный файл `lib/practiceTemplates.ts`)
2. При добавлении — `saveTask()` с копией полей шаблона и новым `crypto.randomUUID()`
3. Отслеживание "какие практики пользователь уже добавил" — через проверку `title` в `getAllTasks()`

### UI

- `components/TasksApp.tsx`:
  - Добавить состояние `showSuggested`, `suggestedExpanded`
  - Секция "Предлагаемые" рендерится, если есть практики, которые пользователь ещё не добавил
  - Кнопка "Добавить" → `saveTask(template)` → refresh
  - Переименовать архив

### i18n

Новые ключи в `lib/i18n.ts`:
- `tasks.suggested` — "Предлагаемые"
- `tasks.suggestedAdd` — "Добавить"
- Для каждой практики: `practice.observer.title`, `practice.observer.desc`, и т.д.

### Иконки

Каждая практика получает `imageUrl` или `thumbnailDataUrl`:
- Для простоты — используем emoji как fallback (title начинается с эмодзи)
- Можно добавить pinterest-ссылку на тематическое изображение (например, "https://i.pinimg.com/736x/xxx.jpg")
