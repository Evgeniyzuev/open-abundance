# Leader Growth Program

Этот документ описывает программу выращивания лидеров Open Abundance: обучение людей с нуля, которые поведут за собой команды и будут растить новых лидеров.

## 1. Концепция

**Цель:** создать воспроизводимый путь от новичка до лидера, который обучает следующих лидеров.

**Принципы:**
- Лидерство — это навык, которому можно обучить
- Лидер растет через действие: привел → помог → обучил → сертифицировал
- Вознаграждение лидера = 10% от роста команды + бонус за выращенных лидеров
- Программа не требует отдельного UI на старте: использует существующие челленджи, рефералы и команды

## 2. Путь от 0 до лидера

### Уровень 0-1: Ознакомление
**Что делает:** проходит onboarding, создает желание, получает первый Core, выполняет базовые челленджи
**Результат:** понимает механику Core/Wallet, умеет пользоваться Today
**Челленджи:** Starter Challenges, Compound Interest Quiz

### Уровень 1-2: Первые шаги как лидер
**Что делает:**
- Приводит первого реферала (друга/знакомого)
- Помогает новичку пройти onboarding
- Публикует первый результат в ленте
- Получает первый командный бонус
**Результат:** понимает механику рефералов и командного бонуса
**Челленджи:** "Приведи первого участника", "Помоги новичку", "Опубликуй результат"

### Уровень 2-3: Становление лидером
**Что делает:**
- Достигает уровня 2 (Core)
- Получает статус лида (может вести команду)
- Набирает первых участников в команду
- Использует Лидерство (capacity = level × 10)
- Получает регулярный командный бонус
**Результат:** действующий лид с активной командой
**Челленджи:** "Стань лидером", "Набери команду", "Получи первый командный бонус"

### Уровень 3+: Сертифицированный лидер-наставник
**Что делает:**
- Обучает участников своей команды
- Помогает участникам достичь уровня 2 и стать лидами
- Получает бонус за выращенных лидеров
- Может сертифицироваться по направлениям
**Результат:** лидер, который растит следующих лидеров
**Сертификаты:** "Наставник", "Лидер роста", "Эксперт направления"

## 3. Механики вознаграждения

### Базовая (реализована)
- 10% от суточного прироста Core прямых участников команды
- Начисляется ежедневно после daily rate
- Каскад: лид лида получает 10% от роста лида (включая бонусы от его команды)

### За выращивание нового лидера (предлагается)
Когда участник команды достигает уровня 2+ и становится лидом:
- Бывший лид получает **постоянный бонус к Лидерству** (+5 к capacity)
- Бывший лид получает **бейдж/сертификат "Наставник"**
- Бывший лид получает **10% от командного бонуса нового лида** (делегированный рост)

### Сертификаты навыков (предлагается)
Направления сертификации:
- **Привлечение и активация** — как приводить и активировать новых участников
- **Производство контента** — как создавать контент, который привлекает и удерживает
- **Наставничество** — как обучать и поддерживать участников
- **Продажи** — как продавать свои товары/услуги на marketplace
- **Проектная работа** — как вести проекты внутри сообщества

Экономика сертификата:
```text
Wallet пользователя уменьшается
→ та же сумма необратимо добавляется в Core
→ пользователь получает непередаваемый проверяемый сертификат
```

## 4. Статус реализации

### Реализовано:
- RPG-модель Лидерства: база `level × 10`, использованное/свободное Лидерство
- Referral claim, командная связь, очередь распределения
- Командный бонус 10% (миграция подготовлена)
- Базовые челленджи (Starter, Compound Interest)
- Уровни Core (level = floor(sqrt(balance / 10)))

### Не реализовано:
- **Обучающие челленджи для лидеров:** "Приведи первого", "Помоги новичку", "Стань лидером"
- **Сертификация лидеров:** направления, критерии, проверка, выдача сертификата
- **Бонус за выращенных лидеров:** +5 к capacity, бейдж "Наставник", 10% от бонуса нового лида
- **UI "Мой путь лидера":** экран с этапами, прогрессом, следующими шагами
- **Учебные материалы:** контент-план, структура курсов, методички
