# Один путь: Путь, Тропы, Нова, Запас

Решение основателя 2026-11-27: приложение собирается в четыре места вместо пяти вкладок и 22 подвкладок, ничего не удаляется. Видение с макетами: https://claude.ai/artifact/5sFMkEp8ECaagMsPzTY4V8

- **Путь** вместо Главной: желание сверху, тропа из точек посередине, один следующий шаг внизу, рюкзак строкой.
- **Тропы** вместо Ленты: истории участников с развилками, «Хочу так же» ставит шаг автора на свою тропу.
- **Нова**: разговор, итог недели, встреча с лидом, просьбы.
- **Запас**: рюкзак (Core, Кошелёк, сундуки, находки, Маркет) со свойствами по тапу.

Правила визуального языка: форма точки говорит, что это (круг — задание, огонь — вызов, запечатанный ромб — миссия-тайна, квадрат — сундук); цвет — сфера жизни из мини-пути; одна главная кнопка на экране; персонаж из мини-пути идёт по тропе; награда — короткая сцена, после неё «Поделиться».

## Шаг 1. Путь (сделано, по флагу)

`components/PathHome.tsx`, `lib/pathTrail.ts`, тест `pnpm test:path-trail`. С 27.11.2026 включён для всех, `/?path=0` выключает на устройстве, `/?path=1` включает обратно. «Заметил» переименован в «Быструю заметку» и живёт в Желания → Задачи.

- Тропа снизу вверх: три последних пройденных шага пути, текущий шаг с персонажем и подписью, три следующих (всю длину не показываем). Сбоку: вызовы и миссии со словом, две запечатанные миссии дня, сундук, если его можно открыть.
- Следующий шаг: сундук, потом данное слово, потом текущее задание, потом миссия-тайна.
- Тап по точке открывает её свойства и одно действие.
- Всё, что было на Главной (Нова дня, встреча с лидом, цель дня, задачи, лента и прочее), лежит в одной свёртке «Ещё на сегодня».
