# Открытый цех: задачи для внешних участников

Статус: черновик 2026-10-22. Формат решён с основателем: любой может вносить код как в опенсорсе или брать небольшие задания за награду. Эксперимент запускается без юридических договоров, как частные лица; награды сначала платятся из собственных средств проекта, без обещаний дохода.

Правила входа — в [CONTRIBUTING.md](../CONTRIBUTING.md). Размеры наград ниже — стартовые ориентиры, меняются решением основателя. Принимает вклад человек.

## Дорожка 1. Код (опенсорс)

| Задача | Примерная награда | Как проверить |
|---|---|---|
| Описать запуск проекта на чистой машине и исправить, что не заработало | 5 Core | Новичок поднимает проект по инструкции |
| Добавить `LICENSE` после решения основателя | — | Решает основатель |
| Тесты для одного из `scripts/verify-*.mjs` на граничные случаи | 3–5 Core | `pnpm test:*` проходит |
| Проверка интерфейса на слабом Android и маленьком экране, список багов с скриншотами | 3 Core | Баги воспроизводятся |
| Доступность: подписи, контраст, фокус на одном экране | 3 Core | Проверка клавиатурой и читалкой |
| Перевод одного guide-раздела на новый язык (`lib/guidesEn.ts`) | 5 Core | Носитель языка читает |
| Исправление мелкого бага из issues с воспроизведением | 3–10 Core | Тест или шаги проверки |
| Скрипт проверки битых ссылок в docs/ | 5 Core | Скрипт находит тестовую ошибку |

## Дорожка 2. Микрозадания

| Задача | Примерная награда | Результат |
|---|---|---|
| Прочитать стартовый путь новичка и записать, где запутались | 1 Core | Короткий текст или голосовое |
| Найти 3 сообщества, где обсуждают совместные закупки или взаимопомощь | 1 Core | Список со ссылками и правилами площадок |
| Перевести короткий текст приглашения (INVITATION_TEXTS.md) | 1–2 Core | Текст на языке |
| Снять 30-секундное видео «что такое OA» по сценарию | 3 Core | Ссылка на видео |
| Проверить 5 страниц /m или /@nick/shop и описать проблемы | 1 Core | Список проблем |
| Ответить на 5 вопросов новичков в сообществе | 2 Core | Ссылки на ответы |

## Роль ИИ-координатора

- Помнит, что человек уже сделал и что умеет, и предлагает следующую задачу чуть сложнее.
- Знакомит людей с похожими задачами и интересами.
- Следит за задачами без исполнителя и предлагает основателю пересмотреть награды.
- Не принимает вклад, не определяет награды и не распоряжается деньгами.

## Метрики роста

Новые вкладчики в неделю, доля вернувшихся на второй месяц, доля пришедших по рекомендации, время от «взял задачу» до принятия.

## Открыто для основателя

Лицензия на код (MIT/Apache 2.0 или AGPL), форма награды (Core, Wallet или оба), кто ревьюит на старте, где публикуется доска (страница в приложении или GitHub Issues).
