# Реферальная программа v2 (2026-10-26)

Решение Evgen: вариант A с правками. Каждый узнаёт о программе в первый день (квест «Пригласи друга» берётся сам), видит, сколько дают 10 подтверждённых друзей, и дальше растёт с командой через лидерский бонус.

## Награды пригласившему

Суммы лежат в `referral_reward_settings`, начисляются сами, без лимита в день, один раз за каждого приглашённого и вид награды (`referral_rewards`).

| Событие | Core | Wallet | Вид |
|---|---|---|---|
| Регистрация по ссылке | $0.1 | | `signup` |
| Приглашённый выполнил любое задание, кроме регистрации | $0.5 | $0.05 | `active` |
| То же, если пригласивший прошёл «Я не робот» (x2 в сумме) | +$0.5 | +$0.05 | `active_bonus` |
| Приглашённый прошёл «Я не робот» | $1 | $0.1 | `humanity_confirmed` |
| Лидерский бонус, бессрочно | 10% от роста Core команды | | как раньше |

- Wallet-часть идёт в Wallet только тому, кто прошёл «Я не робот», иначе в Core. Так фейковые аккаунты не превращаются в деньги для вывода.
- Кто пройдёт «Я не робот» позже, получает доплату `active_bonus` за всех активных приглашённых, которые пришли раньше.
- Старая награда за 2-й уровень приглашённого обнулена (`level_two_core_amount = 0`), её заменяет `active`.
- При запуске v2 уже приглашённым начислено по новым правилам за то, что они уже сделали.

## Квесты

- «Пригласи друга» (`has_referral`): +$1 Core и +$0.1 Wallet, когда по ссылке зарегистрировался первый человек. Доступен всем с первого дня, без «первого результата» и без «Я не робот».
- «5 друзей в деле» (`referrals_active_5`) и «10 друзей в деле» (`referrals_active_10`): по +$1 Core и +$0.1 Wallet, считаются приглашённые с наградой `active`. По общему правилу награда больше $1 требует «Я не робот».

## Квест «Пригласи друга» по шагам

1. Сюжет: корабль «Изобилие» собирает экипаж, каждый новый человек поднимает парус.
2. Награды: все бонусы с живыми суммами из настроек, пример за 10 подтверждённых друзей, что получает сам друг.
3. Смелость: никто не смотрит на других, через час забудут. «Делай свой результат».
4. Рассылка: всем знакомым и незнакомым, скопировать куда угодно, QR в живом разговоре. Кнопки «Поделиться», «Скопировать», «QR-код» и готовые тексты.
5. Вопрос «Что помогло бы приглашать больше?» (несколько ответов).

## Ссылка-приглашение

`/i/<код>`: превью с карточкой (`public/og/invite-ru.jpg`, `invite-en.jpg`), заголовок «<имя> зовёт тебя в Open Abundance», описание «Простые действия и достойные награды. Узнай, сколько можно сделать уже сегодня. Построим ИИ-изобилие вместе!» (без слов про доход и сумм, чтобы превью не резали фильтры; про бонусы рассказываем внутри приложения). Человек сразу переходит на `/?ref=<код>&utm_medium=invite`.

## Аналитика

Раздел 16 ежедневного отчёта (`lib/referralAnalytics.ts`): воронка квеста (открыли → дошли до рассылки → поделились → привели), способы отправки (`invite_shared`: share, copy, qr), ответы на вопрос (`invite_help_answer`), выплаты по видам и предложения, если приглашений мало.
